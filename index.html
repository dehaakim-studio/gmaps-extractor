🔑 Petunjuk Pemasangan API Key

Langkah-Langkah Mengambil API Key:

1. Selesaikan Login / Sign In:
Buka link di browser atau kunjungi langsung https://account.distancematrix.ai/.
Jika diarahkan ke halaman login, masuk menggunakan akun Google atau GitHub yang Anda daftarkan.

2. Masuk ke Dashboard Utama:
Setelah login berhasil, Anda akan diarahkan ke halaman utama Dashboard / Overview.

3. Cari Bagian "API Tokens" atau "API Keys":
Di halaman Dashboard (biasanya terletak di bagian tengah atau menu navigasi sebelah kiri), cari bagian API Token / API Key.
Secara otomatis, DistanceMatrix.ai biasanya langsung menyediakan Default Token saat akun pertama kali dibuat.

4. Salin (Copy) API Key:
Klik ikon Copy (salin) di sebelah string token/key tersebut.
Jika token belum ada, klik tombol "Create Token" / "Generate New Key", berikan nama token (misalnya: My Project), lalu simpan/salin kode API Key yang muncul.

⚠️ Catatan Penting Security:
Link dengan parameter code= dan state= merupakan token akses login sekali pakai (one-time authentication code). Jangan bagikan link lengkap yang berisi code tersebut kepada orang lain untuk menjaga keamanan akun Anda.

📄 Petunjuk Pembuatan Google Sheet URL

Langkah Pertama: Membuka Google Apps Script
- Buka spreadsheet/Google Sheets yang sedang Anda gunakan.
- Pada menu bar atas, klik Extensi (Extensions) > Apps Script.
- Tab baru akan terbuka membawa Anda ke editor Google Apps Script.

Langkah 2: Menulis Kode di Code.gs
- Di panel sebelah kiri, Anda akan melihat daftar file. Secara default sudah ada file bernama Code.gs.
- Hapus kode default function myFunction() { ... } dan ditimpa dari hasil pada Pengaturan Sheet tadi.
- Jangan lupa simpan perubahan dengan menekan tombol Save (ikon disket / Ctrl + S).

Langkah Terakhir : Cara Mendeploy (Deployment)
Cara mendeploy tergantung kebutuhan Anda (apakah ingin dijadikan Web App yang bisa diakses via URL/API, atau sebagai Add-on/Library). Jika Anda membutuhkan URL endpoint (misalnya untuk menerima webhook atau dipanggil dari luar):
- Di pojok kanan atas editor Apps Script, klik tombol biru Deploy > New deployment.
- Pada jendela popup yang muncul, klik ikon roda gigi (Select type) di sebelah Select type, lalu pilih Web app.
- Isi konfigurasi Web App:
    • Description: Isi keterangan singkat (contoh: v1.0 API).
    • Execute as: Pilih Me (email Anda) (Script akan berjalan menggunakan izin akun Anda).
    • Who has access:
      Pilih Anyone (Siapa saja) jika URL ini ingin bisa diakses publik/API tanpa perlu login Google.
      Atau pilih Only myself jika hanya untuk penggunaan pribadi.
- Klik tombol Deploy.
- Jika diminta otorisasi ulang, lakukan proses izin akun google Anda.
- Setelah selesai, Google akan memberikan Web App URL (URL akhiran /exec). Salin dan simpan URL tersebut kedalam kolom URL diatas.
