🔑 Petunjuk Pemasangan API Key

Langkah-Langkah Mengambil API Key:

1. Selesaikan Login / Sign In:
Kunjungi https://account.distancematrix.ai/.

2. Masuk ke Dashboard Utama:
Setelah login, Anda akan diarahkan ke halaman Dashboard / Overview.

3. Cari Bagian "API Tokens" atau "API Keys":
Cari bagian API Token / API Key. DistanceMatrix.ai biasanya langsung menyediakan Default Token saat akun pertama kali dibuat.

4. Salin (Copy) API Key:
Klik ikon Copy di sebelah token tersebut. Jika belum ada, klik "Create Token", berikan nama, lalu salin kode yang muncul.

⚠️ Catatan Penting Security:
Link dengan parameter code= dan state= merupakan token akses login sekali pakai. Jangan bagikan link tersebut kepada orang lain.
